Contributions are welcome to 
[Ox.SleepingGods](https://github.com/Dash/Ox.sleepingGods) companion app.

### Requests & Bug reports
Open an [issue](https://github.com/Dash/Ox.SleepingGods/issues) to report bugs
or ask for enhancements

### Making changes
If you wish to make a change yourself, please feel free.  To do so, create a
fork of this repository in GitHub, make your changes, and then submit a Pull
Request from your branch into the master branch (or other relevant branch)
of this project.
